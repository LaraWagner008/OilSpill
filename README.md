# OilSpillSystem

Система поддержки принятия решений для планирования операций по обнаружению и ликвидации разливов нефти на акватории с использованием групп беспилотных и пилотируемых воздушных судов.

## О проекте

Проект разработан в рамках выпускной квалификационной работы.

Программа моделирует операцию по обнаружению и ликвидации разлива нефти и позволяет оценить рациональный состав парка воздушных судов с учётом временных, эксплуатационных, топливных, материальных и экологических факторов.

## Основные возможности

- моделирование распространения нефтяного пятна;
- учёт скорости и направления течения;
- учёт скорости и направления ветра;
- расчёт скорости и направления дрейфа нефтяного пятна;
- расчёт параметров поисковой операции;
- расчёт применения БПЛА;
- расчёт применения вертолётов;
- расчёт применения самолётов;
- подбор состава группы воздушных судов;
- расчёт эксплуатационных затрат;
- расчёт топливных затрат;
- расчёт материальных затрат;
- оценка экологического риска;
- построение альтернативных сценариев операции;
- графическое отображение результатов;
- визуализация распространения нефтяного пятна.

## Расчётный модуль

Расчётная часть разделена по типам выполняемых операций:

- UAVCalculator — расчёт применения БПЛА;
- HelicopterCalculator — расчёт применения вертолётов;
- AirplaneCalculator — расчёт применения самолётов;
- OperationCalculator — расчёт общих затрат и времени операции;
- EnvironmentCalculator — расчёт параметров дрейфа;
- RiskCalculator — оценка экологического риска.

## Моделирование

OilSimulation отвечает за моделирование распространения нефтяного пятна во времени.

В процессе моделирования учитываются:

- скорость дрейфа;
- направление дрейфа;
- толщина нефтяной плёнки;
- площадь пятна;
- периметр;
- координаты центра распространения.

## Визуализация

Визуальная часть разделена на:

- OilSimulationScene — отображение акватории и нефтяного пятна;
- HUDRenderer — отображение текущих параметров моделирования;
- ChartsManager — построение графиков и панели альтернативных сценариев.
- Работа с базой данных

Для хранения исходных данных используется SQLite.

## DatabaseManager отвечает за:

- подключение к базе данных;
- загрузку исходных условий;
- загрузку расчётных констант;
- загрузку характеристик воздушных судов.

1. Клонировать репозиторий.
2. Открыть OilSpillSystem.pro в Qt Creator.
3. Выбрать подходящий комплект сборки Qt.
4. Выполнить сборку проекта.
5. Запустить приложение.

## Интерфейс
Основное окно позволяет задать исходные параметры операции, включая тип акватории, ограничение по времени и объём разлива.

После выполнения расчёта отображаются рациональный состав группы воздушных судов, затраты, экологический риск и альтернативные сценарии.

## Результаты

В результате расчёта пользователь получает:

- выбранный состав БПЛА;
- выбранный состав вертолётов;
- выбранный состав самолётов;
- количество воздушных судов;
- эксплуатационные затраты;
- топливные затраты;
- материальные затраты;
- итоговую стоимость операции;
- продолжительность операции;
- значение экологического риска;
- уровень экологического риска.
